🤖 AI Todo Assistant

Ollama + Llama3.2 + Structured Output

📌 做了什麼

本專案建立一個 AI Todo Assistant， 使用 Ollama 本地部署的 Llama3.2 模型， 將使用者輸入的自然語言提醒事項解析為結構化 JSON， 並透過網頁介面呈現待辦事項。

⚙️ 怎麼執行

1. 安裝 Ollama

ollama pull llama3.2

2. 執行 Python 程式

python src/main.py

3. 輸入提醒事項

提醒我明天下午三點找老師討論論文

💬 執行結果

輸入：

提醒我明天下午三點找老師討論論文

輸出：

{
  "title":"找老師討論論文",
  "time":"明天下午三點"
}

🤖 AI 使用說明

本專案使用 Ollama 本地部署的 Llama3.2 模型， 採用 Structured Output 技術， 將自然語言轉換成 JSON 格式。

使用者輸入：
「提醒我明天下午三點找老師討論論文」

AI 輸出：

{ "title":"找老師討論論文", "time":"明天下午三點" }

後續可進一步整合至待辦事項系統、 行事曆或通知服務。
